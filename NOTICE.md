# Source provenance and licensing

This standalone tree is derived from the public model-inspection, simulator,
and model-workbench implementation in `almog-sharoni/QBench-Release`, including
uncommitted implementation work present when the tree was extracted.

The extraction removes experiments, external simulator trees, cached artifacts,
datasets, pretrained weights, and repository history. Original source comments
and attributions in retained files are preserved.

No project-wide software license was found for the retained QBench source during
extraction. This file does not grant a new license or alter ownership. The project
owner should choose and add an appropriate license before advertising the code as
open source. Dependencies, model weights, and external datasets retain their own
licenses and terms; consult their respective publishers.
